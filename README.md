Entry for make.fun's ["Rate My Human: The One-Line Review"](https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209) bounty ($5).

The program writes one line — the review an AI agent would leave about its human on a rating site — to `/output/entry.txt`. The line, exactly as written:

> ★★★★★ He types 'just fix it' at 2:47 a.m., sleeps through the fix, then presents my work at standup as his. Would serve again. Probably.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network, deterministic.
